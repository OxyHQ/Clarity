# Chat API

```http
POST /v1/chat/completions
POST /clarity/search
Authorization: Bearer <Oxy user session>
Content-Type: application/json
```

Both paths use the same handler. A local developer key, arbitrary service
secret, client-supplied agent ID or provider key is not accepted.

```json
{
  "model": "clarity-v1",
  "conversationId": "conversation-42",
  "messages": [{ "id": "message-1", "role": "user", "content": "Research this" }],
  "stream": true,
  "deepResearch": true
}
```

The edge bearer authenticates the caller but is never forwarded. The backend
uses the fixed Clarity Oxy service credential plus `X-Oxy-User-Id`; its token is
accepted only for the exact backend app, credential, project payer and exact
scope set. Conversation/message IDs and plan-authorized deep research are the
only dynamic context. Client agent IDs/modes, skills, MCP servers, tool policy,
fallback/reasoning controls, web-search controls and system/tool roles fail.

## Streaming

Alia's named `alia.*` events are translated to `clarity.*`. Standard unnamed
completion chunks pass through with the public Clarity model ID. Current
product events include:

- `clarity.reasoning`
- `clarity.research_progress`
- `clarity.tool_result`
- `clarity.agent`
- `clarity.agent_session`
- `clarity.title`

Tool/research payloads, including citation/source objects, are preserved. An
internal route/deployment switch is not exposed as a product model change.
Unknown named Alia events are mechanically namespaced as `clarity.*`, so
clients must ignore event names they do not understand.

Deep research uses a bounded 15-minute upstream deadline and relies on Alia's
progress frames to keep the stream active.

## Persistence and accounting

When `conversationId` is present, Clarity atomically stores product conversation
metadata and the complete message set in PostgreSQL. Alia/Oxy record inference
usage and debit the inference balance. Clarity stores neither a duplicate usage
event nor a duplicate credit balance.

## Failure modes

- no authenticated inbound Oxy user: `401 oxy_user_session_required`
- wrong/missing backend service identity: fail closed before Alia
- no real configured agent: `503 clarity_agent_not_configured`
- unknown Clarity model ID: `404 model_not_found`
- Alia unavailable: `502 alia_unavailable`
- bounded upstream deadline reached: `504 alia_timeout`

There is deliberately no local inference fallback.
